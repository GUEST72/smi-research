# Search Log

Searches that came up empty — so nobody repeats them from scratch. Append entries directly to `main`, no branch needed.

Format:

```
## <question you searched for>
Searched: <date>, <who>
Checked: <venues / terms / databases searched>
Found: <nothing conclusive as of this date, or a one-line pointer to the answer>
Recheck before: <milestone, if it matters>
```
